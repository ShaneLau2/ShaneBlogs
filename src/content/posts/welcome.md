# 欢迎来到我的博客

这是使用 **Firefly** 主题搭建的个人博客。

## 关于 Firefly

Firefly 是一个基于 Astro 构建的功能丰富的静态博客主题，支持：

- 🌓 亮色/暗色主题切换
- 📝 Markdown 与 MDX 文章
- 🏷️ 标签与分类
- 🔍 全文搜索
- 📱 响应式设计
- 🌐 多语言支持
- 🎨 多种壁纸模式
- ... 以及更多功能

更多信息请查看 [Firefly 文档](https://github.com/shanelau/ShaneBlogs)。
